# Capability and release status

Status recorded at documentation bootstrap, 2026-10-11. Live implementation progress belongs to the core project; this page changes when a qualified release is published.

| Surface | Public promise today |
|---|---|
| SDK packages | Scaffold and development plan; no qualified editor release |
| Native SDKs | Planned delivery for iOS, Android, macOS, Windows and Linux |
| CLI/TUI | Development tracks; check release notes before using document commands |
| Document converters | Planned direction-specific adapters; no broad-format fidelity claim |
| Cloud storage | Host contract and planned reference service; no hosted service |
| Public demo | Planned release-backed playground; no working demo advertised |
| Encryption | Optional planned profiles; no production security claim |

The [architecture roadmaps](https://github.com/edit-ac/architecture) contain task acceptance and qualification evidence. Source checkboxes are task templates, not the runner's live progress. Public documentation will link each supported capability to an immutable package version and evidence profile.
