# Build with edit.ac

edit.ac is being developed as a portable editor SDK: one Rust semantic engine, with web, native and terminal clients. Local editing remains available when collaboration transport is disconnected.

The public API is not yet released. Start with the integration contracts below, then follow the [status page](reference/status.md) for qualified packages and examples.

## Choose a starting point

1. [Choose an integration path](guides/getting-started.md): web, native, terminal or host services.
2. [Understand local edits and saving](guides/local-first.md): durability, offline work and reconnect.
3. [Add extensions](guides/extensions.md): portable semantics and host presenters.
4. [Connect agent editing](guides/agents.md): Markdown proposals through your application's MCP.
5. [Import and export documents](guides/document-formats.md): format directions, fidelity and conversion reports.
6. [Host documents in the cloud](guides/cloud-hosting.md): identity, access control and durable receipts.

Use the [glossary](reference/glossary.md) and [compatibility guide](reference/compatibility.md) when working across platforms.
