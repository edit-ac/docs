# Checked local consumers gallery

`python3 scripts/prepare-gallery.py` derives the page, manifest, complete source directories and deterministic ZIPs from the owning manifests. `--check` rejects stale output. No consumer implementation is copied for maintenance or invented here; downloads are derived bytes.

Use Node24.19.0/npm11.17.0. Run `node --test tests/docs-example-gallery.test.mjs` for source/profile/download integrity plus actual desktop/mobile filters, keyboard search/menu and clipboard. Applicable production executions use the unchanged canonical quickstarts web-react/Astro and playground local-editor/collaboration suites. Source studies never run as qualified consumers.

The source ZIPs include the owning manifests, qualification, fixture, candidate metadata and runner files at original repository-relative paths. They are source downloads to overlay into the qualified docs workspace, not self-contained published SDK installations: unpublished exact tarballs, pinned tools and runner dependencies remain prerequisites. Owning guides explain loading, actual edit/readback, read-only, save/reopen, export/reset differences and disposal. Browser code/table/asset report remains unavailable; no new optional loader is implemented.

Fixture: Apache-2.0 Project kickoff. No providers, credentials, remote host, publication or release qualification. See evidence/example-gallery-20261018/receipt.json for this delivery and retained failures.
