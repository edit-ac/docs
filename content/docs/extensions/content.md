## Configuration and limits

```ts
// Fragment of the complete installed consumer; supply the existing host recovery options.
{ extensions: [Images.configure(), Tables.configure()] }
```

**Options:** Images.configure() and Tables.configure() accept no options. Host asset authority remains outside configuration.

**Dependencies and conflicts:** No declared feature prerequisites/conflicts; duplicates and unknown options reject. Select Markdown separately for Markdown import.

**Initial and deferred costs:** Required-input presenters; selecting an image presenter grants no network service or upload implementation. These are loading boundaries, not benchmark numbers or a budget pass. The source manifest includes SDK-1.11/1.12 and EXT-1.20 receipts and their retained failures. A later mobile admission found disabled lightweight modules retained in the eager graph; its reduction remains owner work. Package archive bytes are not network transfer or startup measurements.

## Input, action and expected outcome

- **Input:** A table with header head and cell Friday; image source ![Kickoff](https://assets.example.test/kickoff.png).
- **Action:** Select Tables and Images, edit the cell to Thursday, then undo.
- **Expected output:** Cell becomes Thursday, then Friday; image data/source stays intact when its asset is unavailable. Missing image is visibly reported.

The [complete checked example](@/docs/examples/extension-configurations.md) supplies initialization once, original source/downloads, independently expected outcomes and cleanup. Headings/lists reuse the [Project kickoff command examples](@/docs/examples/commands.md); this catalog introduces no second implementation.

## Serialization and import

The existing table/image module tuples retain original source for unsupported hosts. Imports require a separately selected qualified codec; PDF remains export-only in conversion guides. See [format support](@/docs/guides/format-support.md) before conversion. Portable semantics and descriptors do not establish a native or terminal presenter. Only the exact local Chromium/production engine cases in the consumer receipt are newly observed here; other platforms remain planned/unqualified by this catalog.

## Accessibility, cancellation and teardown

Cell textareas and image alt text use the existing presenters; image failure retains its source/alt fallback. Host uploads/resolution require explicit host permission and cancellation. destroy/report preserves unsaved edits; no data clearing. Async features remain editor-scoped. Closing a view releases subscriptions and captured resources; do not clear stored documents as teardown.

## Failure and recovery

Report admission errors before mounting, await readiness and expose optional feature failures. Preserve text, source and unknown payloads. Repair compatible assets/permissions and retry only the affected boundary. A local event does not prove a durable or remote save; use the [saving lifecycle](@/docs/reference/lifecycle.md).
