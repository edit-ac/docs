## Configuration and limits

```ts
// Fragment of the complete installed consumer; supply the existing host recovery options.
{ extensions: [], formatting: { marks: { bold: { shortcuts: false, controls: false } } } }
```

**Options:** Core formatting.marks policies: commands, shortcuts and controls independently. No Heading/List facade factory is promised.

**Dependencies and conflicts:** Disabling commands requires shortcuts:false and controls:false; hiding controls does not change admission or permissions.

**Initial and deferred costs:** Baseline engine/input/formatting; no dictionary, parser or resolver selected. These are loading boundaries, not benchmark numbers or a budget pass. The source manifest includes SDK-1.11/1.12 and EXT-1.20 receipts and their retained failures. A later mobile admission found disabled lightweight modules retained in the eager graph; its reduction remains owner work. Package archive bytes are not network transfer or startup measurements.

## Serialization and import

Existing marks and unknown bounded attributes survive hidden controls. Heading/list changes use the existing engine block attributes, not DOM tags as data. See [format support](@/docs/guides/format-support.md) before conversion. Portable semantics and descriptors do not establish a native or terminal presenter. Only the exact local Chromium/production engine cases in the consumer receipt are newly observed here; other platforms remain planned/unqualified by this catalog.

## Accessibility, cancellation and teardown

Keep a keyboard focus target and accessible host command labels. Core input/selection owns IME boundaries. Captured commands become invalid after target changes; dispose captures. Read-only rejects edits. Async features remain editor-scoped. Closing a view releases subscriptions and captured resources; do not clear stored documents as teardown.

## Failure and recovery

Report admission errors before mounting, await readiness and expose optional feature failures. Preserve text, source and unknown payloads. Repair compatible assets/permissions and retry only the affected boundary. A local event does not prove a durable or remote save; use the [saving lifecycle](@/docs/reference/lifecycle.md).
