## Before you start

Use Node24.19.0, npm11.17.0, TypeScript5.9.3 and an explicitly supplied installed Playwright1.64.0. Tests install only pinned local production tarballs offline. The host seeds a real engine checkpoint into IndexedDB once, then opens the existing public facade. Initializing recovery is shared harness setup; extension examples do not copy codec/registry/worker orchestration.

## Example and expected outcome

Start with Due Friday. Select Search and Reorder individually or expand a preset; a sibling with no extensions stays local and unchanged. Insert a prepared bold Kickoff menu result, undo, then check the original text. Edit a table cell Friday→Thursday and undo; retain an unavailable image's source/alt. Configure command-lazy Markdown so input stays literal, then explicitly export. Missing required parser assets reject readiness and preserve source; disposal cannot attach stale work. Headings/lists use the already qualified [Project kickoff command consumer](@/docs/examples/commands.md).

## Failure, cancellation and recovery

Duplicate features, altered factory values, unknown options and incompatible legacy assembly keys reject before a root is reserved. Preserve the host's preview and document. Required parser failure is not ready; repair the asset URL before bounded retry. Async completion after destroy is cancelled. Await destroy and inspect flush failure; never clear the database to make a test pass. The owner closes all engines/storage owners after surface disposal.

## Presenter, cost and migration limits

Portable descriptors list possible presenter families; they are not platform observations. This consumer verifies local Chromium mechanics. Prepared missing-resource failures do not establish actual OS spelling, IME/AT, native or terminal qualification. Code/Pairs facade entries remain contract fixtures. Baseline engine/Yrs/storage remain required; enabled heavy assets are lazy, but lightweight disabled module bytes can remain in the current eager graph. No numerical size/performance/budget claim is made. The SDK loading receipt records initial/deferred graph evidence for its exact older package identities; it is retained evidence, not a measurement of this catalog.
