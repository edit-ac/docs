The browser adapter uses the shared Rust/WASM engine. The [existing walkthrough](@/docs/examples/web.md) names the unpublished source revision and version 0.0.0. Selected local packed evidence is described on the status page; it is not registry installation qualification.

## Before you start

**Prerequisites:** Use the named source checkout and its build instructions. A package tutorial will name immutable JS/WASM/CSS assets and independently tested edit, save and disposal results.

**Tested version:** documentation navigation checked with Zola 0.23.6 and DevLab 0.9.0. No SDK consumer is qualified by this page; see [capability and release status](@/docs/reference/status.md).

## Example and expected outcome

The shared [examples gallery](@/docs/examples/_index.md) records available source previews and planned complete consumers. This entry contains no executable SDK snippet.

## Failure and recovery

If assets fail to load, retain the source and diagnostics. Use matching assets from one version; do not clear saved documents to repair loading.
