**Status: Conceptual path; no supported-platform claim.**

iOS, Android, macOS, Windows and Linux require their own binding, presenter and target-platform evidence. Portable semantic checks do not qualify OS input, IME, accessibility or native views.

## Before you start

**Prerequisites:** Choose one target OS and binding version. Check editing versus preservation support for every enabled extension and require that platform’s consumer before following executable setup.

**Tested version:** documentation navigation checked with Zola 0.23.6 and DevLab 0.9.0. No SDK consumer is qualified by this page; see [capability and release status](@/docs/reference/status.md).

## Example and expected outcome

The shared [examples gallery](@/docs/examples/_index.md) records available source previews and planned complete consumers. This entry contains no executable SDK snippet.

## Failure and recovery

Keep a backup in a compatible format. An unavailable presenter is not permission to discard unknown content or silently fall back to a different schema.

## Migration and compatibility

Check [versions and capabilities](@/docs/reference/compatibility.md), [Migrate to edit.ac](@/docs/migrate/_index.md) and [Compare editors](@/docs/compare/_index.md) before moving existing content.
