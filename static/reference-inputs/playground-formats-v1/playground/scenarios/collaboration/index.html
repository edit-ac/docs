Optional remote hosting remains gated by roadmap28 and requires explicit host authorization, bounded transport and a qualified receipt protocol. This example accepts no remote URL. Read-only is a local input policy; peer updates can still arrive. Export before leaving after a save error. Closing reports unsaved recovery data instead of silently discarding it.
