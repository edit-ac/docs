# edit.ac artwork provenance

The mark preserves the two paths from the user-supplied `edit-text-edit-tools-svgrepo-com.svg`, retained here as `editac-source.svg`.

Source: [Edit Text Edit Tools, uploaded by SVG Repo](https://www.svgrepo.com/svg/238902/edit-text-edit-tools). The source page lists the artwork under [CC0](https://creativecommons.org/publicdomain/zero/1.0/).

Generated variants change color, canvas padding and output format; they do not redraw the mark. The artwork's CC0 status is separate from this repository's Apache-2.0 code license.
