# Local optional formats and package workflows

This unpublished local scenario uses the exact core/web/formats 0.0.0 archives from CNV-1.18-C2-EI canonical2, authenticated by `build-playground-formats.mjs`. Its `profile.json` records archive, installed member, fixture and scenario source hashes. It composes public `openEditorStorage` and borrowed `mountEditorSurface`; the production Session, AssetSession and optional converter own semantics, history, storage and media.

Enable format capabilities to load the optional client and installed manifest. Disabled pages fetch neither the optional entry nor converter/worker/font payloads. Enabling alone starts no conversion worker. Disabling and closing cancel pending work and dispose the client. Installed direction/fidelity labels apply; PDF input remains export-only.

Choose DOCX, ODT or reflowable EPUB and an approved local fixture, then preview. The installed manifest shows separate import/export fidelity labels; no unsupported direction is offered. ODT includes semantic text/marks/lists/table/PNG; EPUB follows OPF spine order with sanitized chapter content and PNG. The immutable fixture is verified before conversion. Review diagnostics, then confirm replacement of the first text block as one history group. Shared prepared ingest/atomic commit retains the complete package and exact PNG in the selected sample’s asset journal. The deterministic fixture transport acknowledges local ingest only, with no upload or external media fetch. Undo/redo and close/reopen use the same owners. Lossy imports require explicit approval and preparation again; malformed packages retain input and reject mutation. Cancel preserves recovery material.

Prepare the selected format export explicitly. Review any loss rejection, approve reported losses and prepare again. Download retained output and captured recovery separately. Inputs and output keep their captured format when the selector changes. Inputs, reports and output remain available in the tab after cancellation or delivery failure. Committed originals survive reopening. After a page reload, Retrieve stored input retrieves the selected format’s latest package from the selected sample’s asset journal. The scenario uses a separate database prefix from the basic playground; other configurations remain independent.

Build with `node scripts/build-playground-formats.mjs`, serve `dist/playground` on loopback, and open `/scenarios/extensions-formats/`. Stop the server afterwards. Basic/collaborative sources retain their owning profiles. Table-text/PDF action scenarios and full DWF-1.10 remain open. No native, registry, hosted, device, performance or release claim follows.

Run `npm run check:playground -- --suite extensions-formats` with Node 24.19.0 for capability and DOCX/ODT/EPUB cases, including independent ZIP/XML/PNG and EPUB spine inspection. Prepared fixtures only; external requests are blocked. Browsers, loopback server and temporary extraction directories close in teardown. A fresh `DOCS_PLAYGROUND_OUTPUT` preserves failures.
